# Cursor指示書｜【緊急】管理画面が「読み込みに失敗しました」になる不具合の修正

対象リポジトリ: `CONV-FKT7-NEW-APP`（VIP Store PWA）
作成日: 2026-08-25
発生バージョン: **1.0.255（本番稼働中）**

---

## 0. 症状と緊急度

本番 1.0.255 で、画面が次のエラーで落ちる。

```
読み込みに失敗しました
Cannot read properties of undefined (reading 'charAt')
```

再読み込みしても復旧しない（同じ画面で同じ処理が走るため）。

**このタスクは最優先です。** 修正 → 動作確認 → デプロイまで一気に行ってください。
（他のタスクの「デプロイ前に止まる」ルールは、今回は適用しません。ただし第4章の確認は必ず行うこと。）

---

## 1. 原因（こちらで特定済み。まず裏取りをしてください）

`charAt` はコードベース内に2箇所しかありません。

| 場所 | 内容 | 疑い |
|---|---|---|
| `src/components/UserAvatar.tsx` 26行目 | `{fullName.charAt(0)}` | **本命** |
| `src/pages/Home.tsx` 589行目 | `{displayName.charAt(0)}` | 低（`?? t(...)` のフォールバックあり） |

### なぜ今になって落ちたか

直前のコミット `82cc847` で、`src/pages/AdminDashboard.tsx` の会員取得から
`where('status', '==', 'active')` の絞り込みを **外しました**（停止中会員を一覧に残すため）。

その結果、**これまで読み込まれていなかった会員ドキュメントも読み込まれるようになりました。**
その中に `fullName` を持たないドキュメント（登録途中で失敗したもの、古い移行データ等）があると、

```ts
fullName: data.fullName as string   // → undefined
```

となり、`UserAvatar` の `fullName.charAt(0)` で落ちます。

> 参考: 先日の重複アカウント調査で、**466名中110名がメールアドレス未登録**でした。
> 不完全なドキュメントが実在する裏付けになります。

### 裏取りの方法

Firebase コンソールで `users` コレクションを開き、**`fullName` フィールドが無い、または空文字のドキュメントが存在するか**を確認してください。
存在すれば原因確定です。**見つからない場合も修正内容は変えず**、そのうえで別の原因を追加調査してください。

---

## 2. 修正内容

### 2-1. `src/components/UserAvatar.tsx`（必須）

`fullName` が無くても落ちないようにする。

```tsx
const initial = (fullName ?? '').trim().charAt(0) || '？'
```

を用意し、表示に使う。

- 表示できる文字が無いときは **`？`**（全角クエスチョン）にする
- `interface Props` の `fullName` を `string | null | undefined` に広げる
- **他の props・サイズ・色の処理は変更しない**

### 2-2. `src/pages/AdminDashboard.tsx`（必須）

会員データを読み込む箇所（170行目付近）で、`fullName` が無い場合の既定値を入れる。

```ts
fullName: (data.fullName as string | undefined)?.trim() || '(名前未設定)',
```

- **会員を一覧から除外しないこと。** 名前が無いことに管理者が気づけるよう、一覧には出す
- `email` など他のフィールドも同様に落ちる可能性があるため、**文字列として扱っているフィールドに `?? ''` などの既定値を入れておくこと**
  （`email` は検索の `toLowerCase()` で落ちる可能性があります。**ここも必ず直してください**）

### 2-3. `src/components/UserManager.tsx`（必須）

同じ理由で落ちる可能性があるため、確認して直す。

- 会員データの読み込みで `fullName` / `email` に既定値を入れる
- 検索処理（`userMatchesTerm` / `normalizeSearchName`）が `undefined` を受けても落ちないようにする
  - `normalizeSearchName(user.fullName)` … `fullName` が undefined でも空文字を返すこと
  - `user.email.toLowerCase()` … undefined なら落ちる。**ガードを入れること**

### 2-4. `src/pages/Home.tsx`（確認のみ）

`displayName` はフォールバックがあるため通常は落ちません。
**念のため 589行目も `(displayName ?? '').charAt(0) || '？'` の形に揃えてください**（1行の防御）。

---

## 3. やってはいけないこと

- **`where('status', '==', 'active')` を元に戻す**
  → 停止中会員を一覧に残すのはオーナー決定事項です。**戻さずに、落ちないように直すこと**
- 名前が無い会員を一覧から**除外する**（気づけなくなるため。`(名前未設定)` で表示する）
- バナー露出強化（案C）を「ついでに」実装する
- 検索機能の仕様を変える
- `npm run lint` の既存エラーを直す
- Firestore のデータを書き換えて回避する（**アプリ側で落ちないようにするのが先**）
