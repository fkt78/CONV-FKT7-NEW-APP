## 0. このタスクのゴール

アフィリエイトバナーに **「ペンギンモバイル」（docomo回線の格安SIM）** を1枚追加する。
**バナーは 6枚 → 7枚**、`CORE_BANNER_SLIDES` は **4枚 → 5枚** になる。

**Cursor 側で画像を作成・変換・差し替えする必要はありません。** そのままコミットに含めてください。

作業は次の2ファイルの編集だけです。

1. `src/components/AffiliateBannerCarousel.tsx` … バナー定義を1件追加
2. `src/locales/{ja,en,vi}/common.json` … 文言を1キー分×3言語追加

## 1. Step 1: `src/components/AffiliateBannerCarousel.tsx`

`CORE_BANNER_SLIDES` 配列の **最後（`nexus-card` の直後、閉じ括弧 `]` の直前）** に、次の要素を追加する。

```ts
  {
    id: 'penguin-mobile',
    bgImage: '/banners/penguin-mobile.webp',
    bgPosition: 'right center',
    i18nKey: 'banner.penguinMobile',
    badgeColor: '#f59e0b',
    href: 'https://png-hikaku-app-fkt78.web.app/',
    labelJa: 'ペンギンモバイル（格安SIM）',
  },
```

追加後の `CORE_BANNER_SLIDES` の `id` の並びは、上から順に次のとおり。

```
local-ad-recruit → ka-nabell → agoda → nexus-card → penguin-mobile
```

### 注意

- `bgPosition` は既存4枚と同じ `'right center'`。**変えないこと。**
- `badgeColor: '#f59e0b'`（オレンジ）はオーナー決定済み。**変えないこと。**
- `href` は **`https://png-hikaku-app-fkt78.web.app/`**（末尾のスラッシュあり）。fkt-office.com 配下ではないので、他のバナーに合わせてアンカーを付けたりしない。
- `labelJa` は GA4 とバナークリック集計（`logBannerClick`）に送られる日本語表示名。**上記の文字列をそのまま使うこと。**
- `FKT_MALL_SLIDE`（固定1枚目）と `useMemo` 内の `fukita-recruit`（固定2枚目）は **変更しない**。
- カルーセルのロジック（`shuffleBannerSlides` / `goTo` / スワイプ / 自動再生 / ドットインジケーター）は **一切変更しない**。ドット数は `slides.length` 由来なので自動的に 6 → 7 になる。
- 10行目付近の JSDoc `（例: banner.agoda）` は **変更不要**。

## 4. 検証（必ず実行）

```bash
# 1) バナー定義が5件になっているか（→ 5）
grep -cE "^\s+id: '" src/components/AffiliateBannerCarousel.tsx   # 固定分を含むので 7 が正解

# 2) 追加したIDとURLが入っているか（各1件ヒットが正解）
grep -n "penguin-mobile" src/components/AffiliateBannerCarousel.tsx
grep -n "png-hikaku-app-fkt78" src/components/AffiliateBannerCarousel.tsx

# 3) 画像が7ファイルか
ls public/banners | wc -l    # → 7

# 4) 画像が実在し、参照パスと一致するか
ls -la public/banners/penguin-mobile.webp

# 5) JSON が壊れていないか（3言語）
for l in ja en vi; do python3 -m json.tool "src/locales/$l/common.json" > /dev/null && echo "$l OK"; done

# 6) bannerキーが3言語とも7個で、penguinMobile があるか
for l in ja en vi; do python3 -c "
import json;d=json.load(open('src/locales/$l/common.json'))['banner']
print('$l', len(d), 'penguinMobile' in d, sorted(d['penguinMobile'].keys()) if 'penguinMobile' in d else '')
"; done

# 7) ビルド
npm run build
```
